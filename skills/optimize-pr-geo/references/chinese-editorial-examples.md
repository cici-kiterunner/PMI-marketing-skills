# 中文标题校准实例

PMI中文稿件的团队试用校准实例：
- 有效示例：“PMI首次亮相进博会，以项目能力连接全球创新与中国实践”。前半交代新闻，后半表达PMI的作用与传播价值，默认保留。
- 不采用的替换：“PMI首次亮相进博会 展示PMIxAI能力生态与AI项目管理认证”。虽列出展品，但“能力生态”含义模糊，且弱化原题的理念、目标与价值。
- 原小标题“从‘会用AI’到‘驾驭AI’：PMIxAI能力生态集中亮相”“从AI到出海与可持续转型，让全球标准服务中国企业高质量发展”“全球标准进入中国，中国实践连接世界”体现主题、能力变化、目的或双向价值；默认保留其逻辑，不以无标点的名词串替换。
- 标点用于清楚表达中文关系，不因文档版式通用偏好删除有用的逗号、冒号、引号或对偶结构。不要把“两部分逻辑”误读为必须拆成两个独立标题或句子。
- 改前后逐项比较：核心理念是否保留、目的价值是否明确、中文是否自然、本节及全文是否一致。若仅增加关键词却削弱以上任一项，撤回该修改。


这些是编辑判断实例，不是所有新闻稿的固定模板。
