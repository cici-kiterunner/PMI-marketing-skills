# 证据与编辑验收

## 外部资料
仅在需要补证据或用户要求时检索。优先官方产品文件、原始报告、研究论文、监管/标准发布机构；核对发表日期、语言、市场、样本与上下文。动态政策和产品条件必须查当前官方材料。不能访问时写清未核验，不把搜索摘要当全文。用户提供的内部批准口径不能自动标成公开证据；如与公开资料冲突，指出冲突并询问，不自行选择。

不要将未公开稿件、内部数字或完整原文发送给外部搜索或第三方评分服务。可用不含内部信息的主题词找公开证据；如必须上传原文，先说明具体服务与内容并取得授权。

## 通过标准
- 修改服务本篇内容与传播意图；能指出具体问题、材料依据及预期帮助，不能仅用“符合GEO规范”解释。
- 未将通用GEO模板、推测问题或理念/品牌/增长目标当作必须加入正文的主张；不适用的方法已跳过。
- 原稿所有关键事实保持原义，新增事实有来源或明确占位标记。
- 现成引言保持原文；拟修订引言不作为已批准引言呈现。
- 核心段落主体、时间、范围清楚；摘引后不扩大含义。
- 标题和导语准确承载新闻，目标问题与本篇内容相关。
- 来源能支持紧邻主张，数字有适用口径；虚构“据研究”不算证据。
- 无固定词长、FAQ数量、品牌提及次数或统计密度配额。
- 不将“可引用”评审判定为真实引用、品牌推荐或转化提升。
