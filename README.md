|---|---|---|

## 新闻与PR稿 GEO 内容优化

**Draft `0.1.0-draft.1` · 市场部内部试用**

连接内容传播与GEO优化：基于文章本身的观点、事实和传播目标，让内容更容易被人理解、被AI准确识别和摘引。保留新闻价值、中文表达和品牌口径，由编辑决定是否采纳每一项建议。

## 同事可以拿它做什么

适用于第三方媒体、微信公众号、官网发布前的新闻稿、PR稿和品牌文章。上传或粘贴原稿就能开始；渠道、受众、核心目标及不可改部分，有的话一起提供。

每次运行的顺序：

1. **改稿前反馈**：推测文章可回答的读者问题、拟传递答案、对应理念/品牌/增长目标及原文支持程度；默认反馈后直接继续工作。
2. **修改对照Word**：新增标黄、删除加删除线，替换同时显示新旧文。保留适当的原标题、引言及已提供配图。
3. **重点修改说明**：3–5项意见、采用标准、预期帮助与取舍，区分建议采纳、可选优化、待确认后处理。
4. **下一步动作**：最多3项。可以部分采纳、保留原文或继续修改，不自动审批、发稿或联系媒体。

**预期效果**是传播意图更清楚、信息关系更明确、事实归属更可靠、摘引后更少失真；不承诺AI引用率、流量、考试报名或续证增长。

## 三个传播目标

| 目标 | 文章合适时重点支持 |
|---|---|
| 理念 | 帮助读者理解项目管理的价值与实践 |
| 品牌 | 用有依据的内容体现PMI专业性和差异，不作无证据的协会优劣比较 |
| 增长 | 支持考试报名、持证后的持续参与与续证；培训由授权合作伙伴提供，培训招生不等同于PMI自身增长目标 |

三个目标按文章实际取舍，不必每篇写齐。产品和认证是承接内容，不能为了GEO强行插入。不编造数据、背书、嘉宾观点或产品功能，不强制FAQ、问句标题、固定段长或关键词次数。

## 最简单的安装方式

把下面这段话发给具备仓库读取及本地安装能力的Agent：

```text
请安装这个仓库中的 optimize-pr-geo Skill：
https://github.com/cici-kiterunner/PMI-marketing-skills
先阅读 README.md 和 INSTALL.md，再按你所在Agent的官方安装机制安装完整的 skills/optimize-pr-geo 文件夹。
若是本地Codex或Claude Code，优先按我的使用范围选择用户级或项目级安装；不清楚范围时问我这一个问题。
若宿主有原生Skill管理器，优先使用原生流程，不直接覆盖托管文件。
先检查是否已有同名版本，更新前保留备份，不改写Skill规则。
验证主文件、所有references及版本完整，告诉我安装位置和调用方法。
如仓库权限或Word生成能力不足，请具体说明；不要索取或输出密码/令牌。
```

仓库为私有时，同事及其Agent都需要已获授权的读取方式。仓库网页能打开，不代表Agent环境已具备访问权限。

完整步骤见 **[INSTALL.md](INSTALL.md)**；首次使用与反馈示例见 **[USAGE.md](USAGE.md)**。

## 快速使用

```text
请用 optimize-pr-geo 优化附件稿件，发布渠道是微信公众号。
核心观点请保留，先告诉我你推测的用户问题与传播目标，再给标黄和删除线的Word对照稿。
```

Claude Code可输入 `/optimize-pr-geo`；本地Codex可显式提及 `$optimize-pr-geo`。其他Agent按自己的Skill选择器或调用机制使用。

## 环境要求与试用状态

- Skill本身是Markdown规则与参考资料，不需要单独API Key、MCP服务或常驻进程；Agent自身的模型和账号要求不包含在内。
- 安装脚本仅使用Python 3.9或更新版本的标准库；需要先取得仓库读取权限。使用Agent安装不要求同事手工运行脚本。
- Word交付需要Agent已有文件生成能力，例如python-docx或等效工具；版式检查需要可用的渲染能力。Skill不自动安装软件或赋予这些能力。缺少能力时必须明确说明。
- 已在当前环境用两篇真实稿件迭代流程，并做结构校验；本地安装脚本仅作隔离目录测试，尚未完整验证所有Agent、操作系统和模型的端到端表现。
- 本仓库不包含新闻稿原件、实验对照Word、配图或PMI指南PDF；只包含规则、必要规范摘要与少量标题校准实例。规范摘要不替代当前批准资料。
